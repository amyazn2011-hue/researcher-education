# تثقيف الباحث – مركز الأبحاث | مدينة الملك سلمان بن عبدالعزيز الطبية

موقع دورة «تثقيف الباحث: أخلاقيات البحث على الإنسان وإجراءاته»: تسجيل المتدرب، 15 درسًا، تقييم ختامي (النجاح 80٪)، وشهادة إتمام قابلة للطباعة.

## النشر على GitHub Pages
1. ارفع ملف `index.html` إلى المستودع (الفرع `main`).
2. من **Settings ← Pages** اختر: Source = Deploy from a branch، Branch = `main` / `(root)`، ثم Save.
3. بعد دقيقة يظهر رابط الموقع بصيغة `https://<اسم-الحساب>.github.io/<اسم-المستودع>/`.

## ملاحظات
- الموقع ملف واحد مستقل (الشعار والخطوط وخلفية الشهادة مضمّنة فيه).
- على GitHub Pages يُحفظ تقدم المتدرب في متصفحه فقط، ولا تعمل لوحة التحكم ولا السجل المركزي للمتدربين؛ هذه الخصائص تعمل في النسخة المنشورة على Claude فقط.
